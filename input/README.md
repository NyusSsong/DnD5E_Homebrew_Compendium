# Input

Drop zone for source content awaiting processing.

Place a source class/subclass text file here as `./input/[descriptive-name].md`, then
ask an agent to process it — see `AGENTS.md` → "Standard workflow" for the steps.

Files in this directory are **not published**: the MkDocs site builds from `docs/`
only. Once a source is processed, its output lives in `docs/classes/` (and the input
file can be removed).
